# 🛒 E-Commerce Backend (Django + Docker)

Production-ready E-commerce REST API built using Django REST Framework, MySQL, Redis, and Docker.

## 🚀 Tech Stack

- Django REST Framework
- MySQL
- Redis (Caching)
- JWT Authentication
- Docker & Docker Compose

## 📦 Features

- Product Management (CRUD)
- Cart System
- Order System (Atomic Transactions)
- JWT Authentication
- Redis Caching
- Pagination, Filtering & Search
- Fully Dockerized Multi-Container Setup
